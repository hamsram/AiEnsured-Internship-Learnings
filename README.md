# Audio Processing & Voice Cloning

##  Overview
This repository contains Python scripts developed during my internship to explore audio processing, signal analysis, data preprocessing, and voice cloning workflows.

It covers techniques for cleaning audio recordings, extracting acoustic features, visualizing audio signals, and preparing datasets for speech-related applications.

##  Repository Contents

| Folder | Description |
|---|---|
| **Data Cleaning** | Audio cleaning, silence removal, resampling, and normalization. |
| **Data Preprocessing** | Audio signal analysis, waveform visualization, FFT, spectrograms, and MFCC extraction. |
| **Dataset Related** | Audio segmentation, silence trimming, and dataset preparation. |
| **Voice Cloning Project** | Audio preprocessing, file management, metadata handling, and speech transcription using Wav2Vec2. |

## 🛠️ Technologies Used
- Python
- Librosa
- NumPy & SciPy
- SoundFile
- Matplotlib
- PyTorch & Torchaudio
- Hugging Face Transformers (Wav2Vec2)

##  Key Learnings
- Audio signal processing and feature extraction.
- Audio cleaning and preprocessing techniques.
- Spectrogram and MFCC analysis.
- Speech recognition using pretrained models.
- Audio dataset preparation for voice cloning applications.

## ⚙️ Getting Started

Clone the repository:

```bash
git clone https://github.com/hamsram/AiEnsured-Internship-Learnings.git
```

Install the required dependencies:

```bash
pip install librosa numpy scipy soundfile matplotlib torch torchaudio transformers
```

**Note:** Update the input and output file paths in the scripts according to your local environment.
